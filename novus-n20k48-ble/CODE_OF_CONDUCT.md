# Code of Conduct

Be respectful, be constructive, assume good faith. This is a small,
safety-sensitive project maintained by volunteers.

- Keep discussion technical and kind. No harassment, personal attacks, or
  demeaning comments.
- Because this software controls equipment that gets dangerously hot, do not
  knowingly suggest or contribute changes that remove safety guards without a
  clear, reviewed rationale.
- Maintainers may edit, remove, or reject contributions and comments that don't
  follow these guidelines.

Report concerns by opening an issue or contacting the maintainer listed on the
repository. Adapted in spirit from the Contributor Covenant.
